# MeowFeed 🐾

Веб-приложение на React — лента случайных фотографий котиков с возможностью
сохранять понравившихся в избранное. Данные получаются из открытого API
[TheCatAPI](https://thecatapi.com) с помощью fetch-запросов.

## Возможности

- **4 страницы**: Главная, Галерея, Любимые, О проекте
- **Fetch-запросы к API**: «котик дня» на главной и лента фото в галерее
  загружаются с `api.thecatapi.com/v1/images/search`
- **Избранное**: сохранение котиков в `localStorage` браузера
- **Светлая и тёмная тема**: переключатель в шапке, выбор запоминается
- **Переиспользуемые компоненты**: Header, Footer, Loader, FavoriteButton, ThemeToggle
- **Стили в отдельных CSS-модулях** для каждого компонента и страницы
- **Адаптивность**: мобильное меню-бургер, плавные сетки (1→2→3→4 колонки),
  медиа-запросы

## Запуск

```bash
npm install     # установка зависимостей
npm run dev     # запуск dev-сервера → http://localhost:5173
```

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Как фото попадает в избранное

1. Галерея получает с API массив `{ id, url }`.
2. Клик по кнопке `♡` вызывает `toggleFavorite(cat)` — фото добавляется
   в начало списка (повторный клик удаляет).
3. Список сохраняется в `localStorage` под ключом `cat-favorites`.
4. Страница «Любимые» читает этот список и отображает сетку сохранённых фото.
5. Кнопка показывает состояние: `♡ В любимые` / `♥ В любимых`.

## Примечание

Без API-ключа TheCatAPI действует лимит ~10 запросов в минуту. При превышении
приложение выводит понятное сообщение об ошибке. С ключом (переменная
`VITE_CAT_API_KEY` в `.env`) можно запрашивать данные пород `/v1/breeds`.
